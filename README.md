# AutoCut — ব্রাউজারে অটোমেটিক ভিডিও এডিটর

ব্যাকএন্ড নেই, বিল্ড নেই। শুধু স্ট্যাটিক ফাইল (HTML/CSS/JS), তাই সরাসরি **GitHub Pages**-এ চলে।
সব প্রসেসিং আপনার ব্রাউজারে (FFmpeg WebAssembly); কোনো ফাইল সার্ভারে যায় না।

## GitHub Pages-এ হোস্ট করা
1. নতুন repo বানান, এই ফোল্ডারের সব ফাইল (`.nojekyll` সহ) push করুন।
2. Repo → **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, Folder = `/ (root)`।
3. কিছুক্ষণ পর `https://<username>.github.io/<repo>/` এ সাইট চালু।

`index.html` ফাইল দিয়ে সরাসরি ডাবল-ক্লিক করলে চলবে না (ES modules লাগে)। লোকালি দেখতে: `python3 -m http.server` চালিয়ে `http://localhost:8000` খুলুন।

## FFmpeg কোথা থেকে লোড হয়
- প্রথমে `vendor/ffmpeg/` (আপনার নিজের repo), না পেলে jsDelivr, তারপর unpkg থেকে (~31 MB, ব্রাউজার ক্যাশ করে)।
- নিজের repo-তে রাখতে চাইলে (অফলাইন/CDN ব্লক হলে): `./scripts/vendor-ffmpeg.sh` চালিয়ে `vendor/ffmpeg/` commit করুন।
- সিঙ্গেল-থ্রেড FFmpeg ব্যবহার হয়, তাই GitHub Pages-এ বিশেষ হেডার (COOP/COEP) লাগে না।

## কীভাবে কাজ করে
- Main Video + Main Audio দিলেই এডিটর খুলে যায়। চূড়ান্ত দৈর্ঘ্য = মেইন অডিওর দৈর্ঘ্য।
- ভিডিও ছোট হলে ক্লিপ নরমাল → রিভার্স → নরমাল… এভাবে রিপিট; শেষ ক্লিপ প্রয়োজনমতো কাটা।
- ব্যাকগ্রাউন্ড অডিও ছোট হলে লুপ, বড় হলে শেষে কাটা। রিপিট সংখ্যা বদলানো যায়।
- লোগো ডিফল্টে নিচে-বামে (প্রস্থ/উচ্চতার ৩% মার্জিন), প্রিভিউতে টেনে সরানো যায়; এক্সপোর্টে একই পজিশন।
- টাইমলাইনে ক্লিপ বাছুন, মোড বদলান, ট্রিম (ডান কিনারা টানুন বা শুরু/শেষ লিখুন), সরান, কপি, মুছুন। Undo/Redo: Ctrl+Z / Ctrl+Shift+Z। Space = Play/Pause।

## সীমাবদ্ধতা
- প্রিভিউতে রিভার্স অংশ ফ্রেম-বাই-ফ্রেম সিক করে দেখানো হয় (ব্রাউজার পেছনে চালাতে পারে না), তাই একটু কম মসৃণ হতে পারে। এক্সপোর্ট করা ফাইলে ঠিক থাকে।
- রিভার্স অংশে মূল ভিডিওর সাউন্ড বন্ধ থাকে।
- ব্রাউজারে FFmpeg ধীর। বড়/হাই-রেজোলিউশন ভিডিওতে আগে "ড্রাফট" কোয়ালিটি চেষ্টা করুন। খুব বড় ফাইলে মেমোরি শেষ হতে পারে (ডেস্কটপ Chrome/Edge/Firefox সবচেয়ে নিরাপদ)।
- আউটপুট ফ্রেমরেট = মূল ভিডিওর ফ্রেমরেট (১৫–৬০ এর মধ্যে)। অডিও AAC 192k।
